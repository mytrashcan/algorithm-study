## Hash Functions

- hash function $h$: $U \rightarrow \{1, ...,n\}$는 $U$의 원소를 bucket으로 매핑하는 함수이다.

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%209.%20Data%20Structures%20II/image%202.png)

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%209.%20Data%20Structures%20II/image%203.png)

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%209.%20Data%20Structures%20II/image%204.png)

- 우리의 목표는 function h를 통해 어떤 input이 들어와도 spread 된 버킷을 만드는 것 이다. (O(1)을 위해)
- 그러나 이는 불가능하다!!!
    - M개 → n개 버킷
    → 최소 한 버킷에 M/n개 이상 존재
    → Adversary가 그 버킷 원소 n개 선택
    → SEARCH = O(n) ❌

## Uniformly Random Hash

- $h$: $U \rightarrow \{1, ...,n\}$가 uniformly random function이라 해보자.
    - 이 의미는 h(1)은 1~n 인 uniformly random 수 이다. h(2), …, h(M)도 동일
- 즉 최악의 input이 들어와도 bucket에 어떻게 배치될 지 모른다는 것.

---

### Expected number of items in bucket?

- $E[$number of items in $u_i$’s bucket$]$ = $\Sigma_{j=1}^nP\{h(u_i) = h(u_j)\}$이다.
    - 이를 정리하면 1 + (n-1)/n ≤ 2 이다.
- 위 식에 의하면 time of INSERT/DELETE/SEARCH가 O(1)이다.
    - 그러나, 정말 이게 유용할까?

---

### Truth

- 저장 비용 = M·log(n) bits
Direct Access = M bits
→ 오히려 더 나쁨! ❌

## Hash familes

- Hash family(H)는 hash functions(h)의 모음이다.
- Example:
    - H = { function which returns the LSD, function which returns the MSB }
    - H에서 h를 랜덤하게 선택한다 → 그것이 hash function이 된다.
- 그러나 이러한 경우에도 한계가 있음…
    - 만약 입력이 101, 11, 121, 141 이런식이면 어떡할 것 인가..?

---

### Universal hash familes

- 모든 $u_i \neq u_j$에 대해 $P_{h\in H}(h(u_i) = h(u_j)) \le 1/n.$
    - 이는
1. 소수 $p \ge M$선택.
2. Define:
    1. $f_{a,b}(x) = (ax+b)\space mod \space p$
    2. $h_{a,b}(x) = f_{a,b}(x) \space mod \space n$
    3. $H = \{ h_{a,b}(x) : a \in \{1,...,p-1\}, b \in \{ 0,..,p-1\}\}$
- H는 universal hash family 이다.

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%209.%20Data%20Structures%20II/image%205.png)

<aside>
💡

f는 내 element를 먼저 안겹치게 해줌(이 과정에서 충돌 발생 안함)

h는 내 elements를 고루고루 퍼트려 줌(이 과정에서 충돌 발생 할 수 있음, 확률 1/n)

</aside>

- 해시 함수 h를 저장할 때 O(log M) 만큼의 비트를 필요로 한다.
    - 우리는 두 수 a, b만 알면 됨.
    - 2log(p) bits. (p ≥ M)
    - p를 선택하는것, 그것이 O(log(M))임.
- 또한, a와 b가 주어지면 h의 계산 또한 빨라짐. O(1)

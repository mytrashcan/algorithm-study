## Divide And Conquer

- Divide: 문제의 크기를 작은 크기로 쪼개자.
- Conquer: 쪼개진 문제를 풀어서 쪼개기 전 문제를 풀자.

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%203.%20Divide%20And%20Conquer%20I/image.png)

### Advantages

- 어려운 문제를 푸는데 효과적이다.
    - 어려운 문제를 간단한 문제 여러개로 쪼개서 풀 기 때문.

### 1. 실제로 잘 작동하는가?

이때, loop invariants를 통해 증명할 수 있다.

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%203.%20Divide%20And%20Conquer%20I/image%208.png)

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%203.%20Divide%20And%20Conquer%20I/image%209.png)

Merge Sort’s loop invariants:

1. 루프의 각 반복이 시작될 때, 서브배열 A[p..k-1] 은 L과 R에서 가장 작은 (k-p)개의 원소들을 정렬된 순서로 담고 있다.
2. 또한 L[i] 와 R[j] 는 각자의 배열에서 아직 A로 복사되지 않은 원소들 중 가장 작은 값이다.
1. Initialization (루프 시작 전에 성립하는가?)
    1. k = p 이므로 A[p..k-1] = A[p..p-1] → 빈 배열
    빈 배열은 0개의 최솟값을 담고 있으므로 성립
    2. i = j = 1 이므로 L[1], R[1] 은 각각의 배열에서
    아직 복사 안 된 원소 중 가장 작은 값
2. Maintenance (반복 중에도 계속 성립하는가?)
    1. L[i] ≤ R[j] 인 경우:
    → L[i]가 복사 안 된 원소 중 가장 작은 값
    → A[k] = L[i] 로 복사
    → k와 i를 각각 +1 하면 다음 반복에도 invariant 성립
    2. L[i] > R[j] 인 경우:
    → R[j]를 A[k]에 복사하고 j를 +1 → 마찬가지로 성립
3. Termination (루프 종료 시 원하는 결과를 보장하는가?)
    1. k = r + 1 이 되면 루프 종료
    → A[p..k-1] = A[p..r] 이 (r-p+1)개의 가장 작은 원소들을
    정렬된 순서로 담고 있음
    → L과 R에 남은 원소는 ∞ (sentinel) 뿐

따라서 A[p..r]이 완전히 정렬됨

### 2. 빠른가?

Divide and Conquer 알고리즘은 자기 자신을 재귀 호출하기 때문에, 런타임을 **재귀식(Recurrence Relation)** 으로 표현할 수 있다.

> 피보나치 수열의 재귀적 정의는 T(n) = T(n-1) + T(n-2) 이다.
> 

Divide & Conquer의 일반적인 재귀식 형태:

<aside>
💡

             ⎧ Θ(1)                    if n ≤ c
T(n) =  ⎨
             ⎩ aT(n/b) + D(n) + C(n)  otherwise

</aside>

| 항 | 의미 |
| --- | --- |
| `aT(n/b)` | **Conquer** — a개의 부분 문제를 각각 크기 n/b로 재귀 해결 |
| `D(n)` | **Divide** — 문제를 나누는 비용 |
| `C(n)` | **Combine** — 결과를 합치는 비용 |

이제 Merge Sort의 시간 복잡도를 분석해보자.

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%203.%20Divide%20And%20Conquer%20I/image%203.png)

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%203.%20Divide%20And%20Conquer%20I/image%202.png)

Divide: 배열 중간 인덱스를 계산, 즉 그림에서 q = [(p + r)/2] 이므로 D(n) = $\Theta (1)$

Conquer: 재귀적으로 두 subproblem을 해결한다. 이때 각각의 크기는 [n/2] 이므로 T([n+2]) + T([n/2]) 이다.

Combine: 두 subarray를 합병하는 작업은 $\Theta$(n)의 시간이 걸린다. 즉 C(n) =  $\Theta (n)$

따라서 재귀식은:

<aside>
💡

T(n) = Θ(1)                                        if n = 1
T(n) = T([n/2]) + T([n/2]) + Θ(n)  if n > 1

</aside>

재귀식을 구했으나… 별로 유용하지 않다. 그래서 점화식을 유용하게 쓸 수 있도록 closed form으로 변환 해야 한다.

### Translate a recurrence relation of T(n) to a closed form expression of T(n)

1. Big-$\Theta$의 정의를 사용해, Theta들을 유한한 항으로 재작성하자.

<aside>
💡

T(n) = $c_1$                                          if n = 1
T(n) = T([n/2]) + T([n/2]) + $c_2n$  if n > 1

</aside>

1. n 은 2의 거듭제곱으로 가정

<aside>
💡

T(n) = $c_1$                                          if n = 1
T(n) = **2T(n/2)** + $c_2n$                     if n > 1

</aside>

1. c = max{c1, c2} → 상수 하나로 통합

<aside>
💡

T(n) = $c$                                          if n = 1
T(n) = 2T(n/2) + $cn$                     if n > 1

</aside>

끝.

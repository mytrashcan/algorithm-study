## Floyd-Warshall Algorithm

- DP 알고리즘임.
- All-Pairs Shortest Path 알고리즘임.
    - 즉, 모든 u, v에 대해서 u to v의 shortest path를 알고 싶을때 사용함.
    - single source s로부터만 시작하는게 아님.
    
    ![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2014.%20Dynamic%20Programming%20II/image.png)
    
- Naive solution: $O(n^2m)$
    
    ```cpp
    for all s in G:
    	Run Bellman-Ford on G starting at s.
    ```
    

## Recipe for applying DP

### Step 1: Identify optimal substructure

- 어떤 그래프에서 vertex 마다 임의로 index 1, 2, … , n를 매기자.
- Sub-problem(k-1):
    - u 에서 v로 가는 path에서 shortest path인데, vertex의 구성이 {1, … , k-1}인 shortest path.
- $D^{(k-1)}[u,v]$:
    - Sub-problem(k-1)의 정답

### Step 2: Find a recursive formulation for the value of the optimal solution

- Step 1에서 $D^{(k-1)}$를 사용하여 어떻게 $D^{(k)}[u,v]$를 찾는가?

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2014.%20Dynamic%20Programming%20II/image%201.png)

1. Case 1에서 $D^{(k)}[u,v] = D^{(k-1)}[u,v]$이다.
    1. k-1에서 shortest path였으니, k에서도 shortest path이다.
2. Case 2에서  $D^{(k)}[u,v] = D^{(k-1)}[u,k] + D^{(k-1)}[k,v]$이다.
    1. 보라색 path는 u에서 k까지 {1, …, k-1} 노드를 사용한 shortest path
    2. 핑크색 path는 k에서 v까지 {1, …, k-1} 노드를 사용한 shortest path
    3. sub-path의 shortest path는 곧 shortest path이다.

## Floy-Warshall algorithm (cont.)

- Correctness
    - Proof by Induction (해보세요)
- Running Time: $O(n^3)$
    - Bellman-Ford 보다 빠름
- Storgae
    - n*n 행렬과 original graph를 저장해야 함.

### What if there are negative cycles?

- Bellman-Ford 처럼 Floyd-Warshall도 negative cycles를 detect 가능
    - Negative cycle은 v to v의 cost가 0보다 작을 수 있음.
    - Aka, $D^{(n)}[v,v]<0$
- Algorithm:
    - 플로이드 워셜을 수행한다.
    - 위 조건을 만족하는 어떤 v가 있으면 negative cycle을 리턴한다.

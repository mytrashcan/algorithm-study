## Undirected Graphs

- V is the set of vertices
- E is the set of edges
- Formally, a graph is G = (V, E)

### Example

- V = {1, 2, 3, 4}
- E = { (1,3), (2,4), (3,4), (2,3) }
- Vertex 4의 degree는 2이다.
    - degree: 노드의 차수, vertex에 연결된 edge의 개수
- Vertex 4의 이웃은 2와 3이다.

## Dirceted Graphs

- V is set of vertices
- E is the set of **DIRCETED** edges
- Formally, a graph is G = (V, E)

### Example

- V = {1, 2, 3, 4}
- E = { (1,3), (2,4), (3,4), (2,3) }
- Vertex 4의 in-degree는 2이다.
Vertex 4의 out-degree는 1이다.
    - degree: 노드의 차수, vertex에 연결된 edge의 개수
- Vertex 4의 in-이웃은 2와 3이다.
Vertex 4의 out-이웃은 3이다.

## DFS (Depth First Search)

- 가능한 deep하게 Searching 하는 기법

![DFS를 수행해보라. (undirceted graph)](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2010.%20Graph%20Algorithms%20I/image%205.png)

DFS를 수행해보라. (undirceted graph)

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2010.%20Graph%20Algorithms%20I/image%206.png)

w: input vertex

```python
DFS(w, currentTime):
	w.startTime = currentTime
	currentTime += 1
	Mark w as in progress
	for v in w.neighbors:
		if v is unvisited:
			currentTime =
				DFS(v, currentTime)
			currentTime += 1
	w.finishTime = currentTime
	Mark w as all done
	return currentTime
```

- DFS는 Starting point에서 도달할 수 있는 모든 노드들을 찾는다.
- DFS는 connectoed components(연결 요소)를 찾는데 사용될 수 있다.

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2010.%20Graph%20Algorithms%20I/image%207.png)

### Running time ( n = vertex 수, m = edge 수 )

- 단지 connected component를 탐색하려면:
    - 우린 오직 각각의 노드를 기꺼해야 두번 본다.
    - 그리고 기본적으로, 그 외에는 아무것도 하지않는다.
    - 그러므로 $O(m)$
- Whole graph를 탐색하려면:
    - connected component를 하나하나 탐색한다.
    - 이는 $O(n+m)$만큼의 시간이 걸린다.
    
    ![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2010.%20Graph%20Algorithms%20I/image%208.png)

## Topological Ordering

- Q. package dependency graph가 주어졌을 때 너는 어떻게 정확한 순서로 package를 install 할 것 인가?
    - Dependency graph가 cycle이 없다고 가정하자: Directed Acyclic Graph (DAG)

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2010.%20Graph%20Algorithms%20I/image%209.png)

### What is a DAG?

- DAG는 directed graph 이면서 dirceted cycle이 없는 것 이다.

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2010.%20Graph%20Algorithms%20I/image%2010.png)

### Topological Ordering

- DFS의 응용.
- DAG의 vertices에서 순서를 찾아라. 그러면 모든 dependency가 만족할 것.
    - 만약 v가 w전에 온다면, w → v edge는 존재하지 않는다.

![start 0에서 시작해서 노드방문 할때마다 +1 더이상 갈 길이 없다면 end 표기하고 돌아오기](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2010.%20Graph%20Algorithms%20I/image%2011.png)

start 0에서 시작해서 노드방문 할때마다 +1 더이상 갈 길이 없다면 end 표기하고 돌아오기

### Theorem

- DAG에서 DFS를 실행할 시 다음이 성립한다.

![B.finishTime < A.finishTime](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2010.%20Graph%20Algorithms%20I/a04baa75-f23e-4f2c-bb30-cd104d135cdf.png)

B.finishTime < A.finishTime

### Proof

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2010.%20Graph%20Algorithms%20I/image%2012.png)

- Case 1: DFS트리에서 B는 A의 조상이다.
    - Then
    
    ![B.finishTime < A.finishTime](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2010.%20Graph%20Algorithms%20I/image%2013.png)
    
    B.finishTime < A.finishTime
    
- Case 2: DFS트리에서 B는 A의 조상이 아니다.
    - DFS트리에서 A는 B의 후손이 될 수 없다. 그렇지 않다면 cycle이 존재할 것 이다.
    - 반드시 B를 A보다 먼저 탐색해야 한다.
        - 그렇지 않으면
    - Then
    
    ![B.finishTime < A.finishTime](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2010.%20Graph%20Algorithms%20I/image%2014.png)
    
    B.finishTime < A.finishTime

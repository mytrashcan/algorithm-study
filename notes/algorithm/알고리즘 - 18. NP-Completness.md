## Algorithmic vs Problem Complexity

- Algorithmic Complexity: 이 computation을 perform하기에 얼마나 어렵나
- Problem Complexity: 이 문제를 푸는데 얼마만큼의 시간이 걸리는가
- Computational Complexity: 어떤 문제가 얼마나 어려운지 분류하는 것

## Decision & Optimization Problems

- Decision Problem
    - yes or no로 대답할 수 있는 question & input
- Optimization Problem
    - “best” value를 찾아야 하는 question
    - Optimization Problem은 Decision Problem으로 cast할 수 있다.

> Decision Problem은 Optimization Problme보다 쉽다.
> 

## Class of “P” Problems

- polynomial time에 solvable한 문제들
- Polynomial-time algorithms
    - Worst-case running time is $O(n^k)$ for some constant k…
    - 입력 크기 n에 대해 n^k 형태로 표현 가능한 시간 (k는 상수!)
- Example of Polynomial times
    - $O(n^2), O(n^3), O(1)$…
- Example of Non-Polynomial times
    - $O(2^n), O(n^n), O(n!)$…

### Tractable/Intractable Problems

- P에 속하는 문제들을 Tractable이라 함
- P에 속하지 않는 문제들을 Intractable or unsolvable이라 함
    - non-polynomial algorithm이 항상 polynomial algorithm보다 나쁜건 아님
        - $n^{1,000,000}$과 $n^{logloglogn}$

## Class of “NP” Problems

- Solving problem = 두 가지의 단계:
    1. “Guessing”: 후보 해답 생성 (non-polynomial)
    2. “Verification”: 검증 (polynomial)
- NP algorithms (Nondeterministic Polynomial)
    - Guessing은 non-polynomial
    - Verification은 polynomial

---

- NP 클래스는 NP algorithms로 풀 수 있는 문제들로 구성되어 있음

## P and NP

- P = polynomial time에 풀 수 있는 문제들
- NP = 해답이 주어지면 polynomial time에 검증할 수 있는 문제

## Is P = NP ?

- P인 어떤 문제들은 NP에 속한다: $P \subseteq NP$
- P = NP 인가? → CS 최대의 난제..

## Reductions

- Reduction은 한 문제가 다른 문제보다 쉽다는 것을 표현하는 방법
    - A ≤ B 는 B를 푸는 알고리즘으로 A도 풀 수 있다.
        - 즉, A는 B보다 쉽거나 같다.

```java
A의 입력을 B의 입력으로 변환!

α → [f 변환] → β → [Problem B] → yes/no
                                    ↓
                              A의 답도 yes/no!
```

## Polynomial Reduction

- $A \le_pB$: 함수 f가 존재해서 A의 입력을 polynomial time에 B의 입력으로 변환 가능!
    - A(i) = YES ⟺ B(f(i)) = YES

```java
A: Boolean 집합에서 하나라도 TRUE인가?
B: 정수 집합의 합이 양수인가?

변환 f:
  TRUE  → 1
  FALSE → 0

예: [TRUE, FALSE, TRUE]
  → [1, 0, 1]
  → 합 = 2 > 0 → YES!
  → 즉 하나라도 TRUE! ✓

A(i) = YES ⟺ B(f(i)) = YES ✓
```

## NP-Completeness

- 다음 문제 B는 NP-Complete이다.
    1. $B \in NP$
    2. $A \le_p B \text{ for all A}\in NP$

## P & NP-Complete Problems

- Shortest Path: Polynomial solution: O(VE)
- Longest simple path: NP-Complete

- Euler tour: Polynomial solution: O(E)

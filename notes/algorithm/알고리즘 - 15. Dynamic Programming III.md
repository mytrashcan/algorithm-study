## Longest Common Subsequence

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2015.%20Dynamic%20Programming%20III/image.png)

- Subsequence:
    - **BDFH** 는 A**B**C**D**E**F**G**H**의 subsequence이다.
- 만약 X와 Y가 sequences 이면, common subsequences는 X와 Y 둘 다의 subsequence인 sequence을 의미
    - BDFH 는 ABCDEFGH와 ABDFGHI의 common subsequence이다.
- A longest common subsequence:
    - common subsequence에서 가장 긴 것.
    - ABCDEFGH와 ABDFGHI의 LCS는 ABDFGH이다.

### Step 1: Optimal substructure

- Prefixes:

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2015.%20Dynamic%20Programming%20III/image%201.png)

- $X_i$는 $X$에서 index 1 ~ $i$까지의 값을 의미함
- $C[i,j] = length\_of\_LCS(X_i,Y_j)$라 하자.
    - Examples: $C[2,3]=2, C[4,4]=3$

### Step 2: Recursive formulation

1. Case 1: X[i] = Y[j]인 경우
    
    ![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2015.%20Dynamic%20Programming%20III/image%202.png)
    
    - $C[i,j] = 1 + C[i-1, j-1]$
        - $LCS(X_i,Y_j) = LCS(X_{i-1},Y_{j-1}) \space followed \space by \space A$
2. Case 2: X[i] ≠ Y[j]인 경우
    
    ![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2015.%20Dynamic%20Programming%20III/image%203.png)
    
    - $C[i,j] = max\{C[i-1,j],C[i,j-1]\}$
        - T가 포함되지 않을 시 $C[i-1,j]$
        - A가 포함되지 않을 시 $C[i,j-1]$

- A C G is LCS
- Finding an LCS:
    - takes $O(nm)$ to fill the table
    - takes $O(n+m)$ to recover the LCS
- 실제로 LCS를 table에서 복구하는게 table을 fill하는 것 보다 빠르다.
- 우리는 LCS(X,Y)를 O(mn) 시간에 할 수 있다.

## Knapsack Problem

### 0/1 Knapsack Problem

- weights와 values를 가진 n개의 items이 있고, Capacity가 10인 knapsack을 가지고 있을 때, knapsack을 가장 valuable하게 fill하는 방법이 무엇인가?

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2015.%20Dynamic%20Programming%20III/image%2014.png)

### Step 1: Optimal substructure

- Sub-problems: 더 적은 items를 가지고 있는 0/1 Knapsack
    - solve the problem with few items
    - then more items
    - then yet more items
    - …
- Our sub-problems: x, j로 표현

$$
K[x,j]
$$

- K[x, j]:
    - 용량이 x인 배낭에 
    첫 j개의 아이템만 사용해서 
    얻을 수 있는 최대 가치를 의미한다.
- 인덱스:
    - x = 배낭 용량 (0 ~ W)
    - j = 사용 가능한 아이템 수 (0 ~ n)

### Step 2: recursive formulation

- Goal: K[x, j]를 더 작은 sub-problem들로 표현하고 싶다.

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2015.%20Dynamic%20Programming%20III/8e383ce1-e62f-48b1-9c50-1b160d001b3e.png)

<aside>
💡

- K[x, j]:
    - 용량이 x인 배낭에 
    첫 j개의 아이템만 사용해서 
    얻을 수 있는 최대 가치를 의미한다.
</aside>

1. Optimal solution for first j items **does not use** item j.
    1. $K[x,j] = K[x, j-1]$
2. Optimal solution for first j items **does use** item j.
    1. $K[x,j] =K[x-w_j,j-1]+v_j$
    2. K[x, j]는 j번째 items을 use 했을 때 상태임. 그러니 용량 x - w_j 이고, v_j를 더한 것. 즉 j-1 상태일때 knapsack에서 j를 추가한 것 임.
- Recursive relationship:
    - K[x, j]를 다음에 대한 optimal value라 하자.
        - capacity x
        - with j items.

$$
K[x,j]= max\{K[x,j-1], K[x-w_j, j-1]+v_j\} \\ K[x,0] = K[0,j] = 0
$$

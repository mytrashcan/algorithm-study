## The Runtime of Randomized Algorithms

1. 알고리즘을 작성하고 너의 랜덤화된 알고리즘을 실행한다.
    1. 이때, Running time은 random variable이다. → expected running time이다.
2. 알고리즘을 작성하고, 누군가 랜덤하지 않게 알고리즘을 실행한다.
    1. 이때, Running time은 random이 아니다. → worst-case running time이다.

## BogoSort

- BogoSort는 Array가 정렬될 때 까지 무한번 실행하는 알고리즘이다.
    - 이때, Worst-Case는 Big-O(Infinite) 이다.
    - 이때, Expected는 Big-O(n * n!) 이다.

### Proving Correctness

- QuickSort에서의 Loop invariants
    - A[p…i] 배열에 있는 원소는 pivot보다 작다.
    - A[i+1…j-1] 배열에 있는 원소는 pivot보다 크다.
1. Initialization
    1. Loop가 시작하기 전 A[p … i] and A[i + 1 … j - 1]의 원소는 존재하지 않는다, 즉 Loop invariants를 만족한다.
2. Maintenance
    1. Loop가 진행중일 때 A[j]가 pivot보다 크다면 j만 증가한다. 만약 A[j]가 pivot보다 작거나 같으면 A[j]와 A[i+1]이 swap 된다. 그리고 i 와 j가 증가한다.
3. Termination
    1. Loop가 끝났을 때 j = r 이다, 그러므로 A에 있는 모든 원소는 다음 세 가지 case로 나뉜다.
    A[p … i] ≤ pivot, A[i + 1 … r - 1] > pivot, and A[r] = pivot.

### Analyzing Runtime

- QuickSort의 Running time은 subarray들을 partition하는데 달려있다.
- 만약, subarray가 balanced 하다면, 즉 subarray의 크기가 서로 비슷하게 partition 된다면 MergeSort만큼 빠르게 동작할 것 이다.
    - $T(n) = 2T([n/2]) + \theta(n) = \Theta(nlgn)$
- 만약, subarray가 unbalanced 하다면, 즉 subarray의 크기가 중구난방 하게 partitoin 된다면면 InsertionSort만큼 느리게 동작할 것 이다.
    - $T(n) = T(n - 1) + T(0) + \Theta(n) = \Theta(n^2)$
- QuickSort의 running time은 worst case보단 best case에 가깝다.
    - partition이 1:9로 나누어 진다고 가정해보자, 이때 시간복잡도는 다음과 같다:
    $T(n) \le T(9n/10) + T(n/10) + cn = \Theta(nlogn)$
    
    ![Recursion Tree](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%205.%20Randomized%20Algorithms%20I/image%203.png)
    
    Recursion Tree
    
    - 이때, 1:9 로 나누든, 1:99로 나누든 시간 복잡도는 동일하다. 단 0:10, 0:100과 같이 나누면 $\Theta(n^2)$ 이다.

### Expected Runtime of Randomized QuickSort

- Expected Runtime이 $O(nlogn)$인걸 어떻게 알까? → 두 원소가 비교되는 총 횟수를 세자.

### Steps

1. 랜덤 변수 X 정의
    1. 각 원소 쌍 (i, j)에 대해 랜덤 변수를 정의하자:
    
    <aside>
    💡
    
    $X_{i,j} = 1$     if i와 j가 비교됨 
    $X_{i,j} = 0$     otherwise
    
    총 비교 횟수의 기댓값: $E[X] = \sum\limits_{i=1}^{n-1} \sum\limits_{j=i+1}^n{E[X_{i,j}}]$
    
    </aside>
    
2. $X_{i,j}$의 기대값
    1. $E[X_{i,j}] = P\{X_{i,j}\} \cdot 1 + P\{\bar{X_{i,j}}\} \cdot 0 = P\{X_{i,j}\}$
    2. $P\{X_{i,j}\}$는 i와 j가 비교될 확률이다.
3. $P\{X_{i,j}\}$ 계산
    
    ![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%205.%20Randomized%20Algorithms%20I/image%205.png)
    
    1. 위 그림에서 $P\{X_{6,10}\}$에 대해 생각해보자.
    $P\{X_{6,10}\}$는 7,8,9가 선택 되기 전 6 또는 10이 pivot으로 선택 될 확률이다.
    이때, 7, 8, 9 가 선택 되기 전 이라는 의미는 앞서 나온 수가 pivot으로 선택되는 경우 6과 10은 partitioned 되어 다시는 비교될 수 없기 때문이다.
    따라서 $P\{{X_{6,10}}\}​$는 $2/5$ 이다. 
    2. 이를 공식화 하면 $P\{X_{i,j}\} = 2/(j-i+1)$ 이다.
4. 최종 계산
    1. $E[X] = \sum\limits_{i=1}^{n-1} \sum\limits_{j=i+1}^n{E[X_{i,j}}] = O(nlogn)$

**Randomized QuickSort에서도 여전히 Worst-case는 $\Theta(n^2)$, Expected는 $\Theta(nlogn)$이다.**

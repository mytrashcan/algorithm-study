    - $T^*$와 동일한 개수의 활동을 포함하기 때문이다.

### Summary

- I.H.: t번째 thing을 추가한 뒤 현재 솔루션을 확장(포함)하는 최적의 솔루션이 존재한다
- Base Case: 0개의 활동을 추가한 뒤 현재 솔루션을 확장(포함)하는 최적의 솔루션이 존재한다.
- I.S.:
- Conclusion: last activity를 추가한 뒤, 현재 솔루션을 확장(포함)하는 최적의 솔루션이 존재한다
그러므로 현재 solution은 optimal하다.

## One Common Strategy

1. Make a series of choices
    
    ```python
    Greedy 알고리즘은
    매 단계마다 하나씩 선택을 함!
    
    Activity Selection 예시:
      → 가장 빨리 끝나는 activity 선택
      → 반복!
    ```
    
2. Show that each choice won't rule out an optimal solution
    
    ```python
    매 단계의 선택이
    optimal solution을 배제하지 않음을 보임!
    
    Activity Selection 예시:
      → Greedy 선택 k가 T*에 없더라도
      → T*의 다른 activity와 k를 swap해도
         T*보다 나빠지지 않음!
      → optimal solution이 여전히 존재! ✓
    ```
    
3. After all choices, we must have found an optimal solution
    
    ```python
    Step 2가 매 단계 성립하므로:
    
    모든 선택이 끝난 후에도
    optimal solution을 배제하지 않았음!
    
    → 현재 solution = optimal solution! ✓
    ```
    

### Formally

- **귀납 가정 (Inductive Hypothesis):**
◦ 탐욕적 선택 t번째 이후에도, 성공 가능성은 아직 배제되지 않았다.
- **기저 사례 (Base case):**
◦ 어떤 선택도 하기 전에는 성공이 가능하다.
- **귀납 단계 (Inductive step):**
◦ t번째 선택 이후에도 성공 가능성이 배제되지 않았다면, t+1번째 선택 이후에도 성공 가능성은 배제되지 않는다.
- **결론 (Conclusion):**
◦ 알고리즘의 끝에 도달할 때까지 성공 가능성이 한 번도 배제되지 않았다면, 결국 성공한 것이다.

### Goal

- 트리의 cost은 임의의 문자 하나를 인코딩했을 때의 평균(기댓값) 길이이다. 이를 최소화 하자.

$$
cost(tree) = \Sigma_{leaves\space x}P(x)\cdot depth(x)
$$

### Greedy algorithm

- Greedy Goal: less frequent lettes는 tree의 하단에 위치해야 한다.
- Approach: Bottom-up 방식으로 Greedily하게 sub-tree를 build 한다.

### Huffman Coding

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2016.%20Greedy%20Algorithm%20I/image%2011.png)

### Proof (hard)

- Lemma 1: x, y가 least-frequent letters라 가정하자. x와 y가 siblings인 optimal tree가 존재한다.
    
    ![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2016.%20Greedy%20Algorithm%20I/image%2012.png)
    

---

> C를 Alphabet set이라 하자. c.freq는 C에 있는 alphabet의 frequency 이다.
> 

> x와 y는 C에서 minimum frequency를 가지는 alphabet이다.
> 

> C`은 C에서 x와 y가 제거된 후 z(x + y)가 추가된 Alphabet set이다.
> 
- Lemma 2: T`은 C`에 대해서 optimal이다.
그러면 T'에서 z에 해당하는 리프 노드를, 자식으로 x와 y를 가지는 내부 노드로 바꾸어 얻은 트리 T는 최적이다.

![image.png](%EC%95%8C%EA%B3%A0%EB%A6%AC%EC%A6%98%20-%2016.%20Greedy%20Algorithm%20I/image%2013.png)

- Cost relation
    - $d_T(x) = d_T(y) = d_{T\prime}(z)+1$
    - $x.freq \cdot d_T(x) + y.freq \cdot d_T(y) = (x.freq+y.freq)(d_{T\prime}(z) +1)\\ = z.freq \cdot d_{T\prime}(z)+(x.freq+y.freq)$
- Lemma 2 proof: contradiction
    - T is not optimal tree
    - Cost(T``) < Cost(T)인 optimal tree T``가 존재한다.
    - T``는 x, y를 siblings로 가진다 (Lemma 1)
    - Cost(T``) = Cost(T`` - {x, y}) + x.freq + y.freq (prev. )
    Cost(T`` - {x, y}) = Cost(T``) - x.freq - y.freq
    Cost(T`` - {x, y}) < Cost(T) - x.freq - y.freq (I.H)
    Cost(T`` - {x, y}) < Cost(T`) → Contradiction

### Huffman Coding Works idea

- 허프만 코딩은 계속하서 leaves를 그루핑 하는것 임.
- 그루핑 하고 나서는 그 그룹을 새로운 알파벳으로 취급
- 그러고 나서 이전 lemma를 다시 사용함 → optimality를 rule out 하지 않음
